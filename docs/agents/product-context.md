# Product context: Insights

Today's positioning. Edit freely; the playbook asks the questions, this file holds the current answers. Last set 2026-09-29.

- **Focus:** ERPNext-first adoption. Product-market fit is the next focus, so everything below may change.
- **Primary persona:** an ERPNext pro who knows their business data, not the machinery. Most sites have no separate admin.
- **Secondary persona:** an operator like the maintainer, who wants speed and control and will use advanced features.
- **What the product takes away:** setup before seeing data, modelling joins, choosing what to sync.
- **Where it ships:** Frappe Cloud and self-hosted benches; v3 on `version-3`, develop toward v4.
