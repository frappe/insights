# Who may read a standard dashboard

Type: grilling
Status: open
Blocked by: 03
Repo: insights

## Question

A desk Dashboard is gated by the workspace's roles and by the Dashboard doctype's own permissions, and its charts run with the reader's permissions. An Insights dashboard has a Visibility (Private, Roles, Everyone, Public) and Apply User Permissions on each chart. Decide what the shipped dashboard's file carries so it behaves the way the existing desk dashboard does for the same reader, and what happens for a reader the workspace admits but ERPNext's row permissions do not.
